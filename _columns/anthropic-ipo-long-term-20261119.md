## ② Anthropicとはどのような企業か

Anthropicは、生成AIのClaudeを提供する企業だ。利用者と対話するアプリだけでなく、企業のシステムにAIを組み込む基盤と、開発作業を進める製品を持つ。

| 主な提供形態 | 顧客が利用する目的 | 投資上の見方（分析） |
|:--|:--|:--|
| Claudeアプリ・法人向けサービス | 文書作成、分析、社内業務の支援 | 継続利用・社内展開が契約の定着につながるか |
| Claude API・プラットフォーム | 自社アプリや業務システムへのAI組み込み | 利用量と顧客の業務成果が売上拡大につながるか |
| Claude Code | コードの修正、テスト、移行などの開発作業 | 開発工程への浸透が、継続的な需要を生むか |

Claude Codeは、提案されたコードを人がコピーするだけでなく、権限を与えた環境で作業を進め、利用者が方向付けとレビューを行う製品として提供されている。**技術的な作業範囲が広いことと、あらゆる企業で投資対効果が出ることは別である。**［A4］

収益モデルは従量課金とサブスクリプションの組み合わせだ。2026年1〜9月の従量課金は売上の約79％。個人利用・法人利用と課金方式は別の分類なので、これを「法人売上比率79％」とは呼ばない。顧客は大企業からスタートアップまで広がる一方、従量課金では利用の最適化や競合への振り分けが売上に影響する。［A5］

### Amazon・Googleとの関係

Amazonは出資者であり、AWSを通じた計算資源と販売経路の重要なパートナーでもある。GoogleともTPUを含む計算資源の拡大で提携している。ClaudeはAWS、Google Cloud、Microsoft Azure経由でも提供される。［A6・A7・A8］

**分析：** 提携は供給能力と販売網を広げる。ただし、出資金の受け入れ、クラウドへの支出、顧客からの売上は別の取引であり、出資額を製品需要の証拠にはしない。Googleは提携先であると同時にGeminiを展開する競合でもある。

### Public Benefit Corporationという企業形態

Anthropicはデラウェア州法上の公益目的会社、PBCである。株主の経済的利益に加え、事業の影響を受ける人々と定款上の公益目的を考慮する。IPO資料には、Long-Term Benefit Trustによる取締役選任権や、創業者側への議決権集中も記載されている。非営利団体という意味ではない。［A9］

**分析：** 安全性への注力が企業顧客の信頼を支える可能性がある一方、安全性の判断と短期収益が一致するとは限らない。一般株主の影響力が限られる点も、保有時に受け入れる条件になる。

## ③ IPO時点の企業価値と財務分析

### 公開価格と企業価値は分けて考える

会社の正式発表では、IPOの公募・売出合計は9億8,000万株。83ドルを掛けた**募集・売出総額は813.40億ドル**となる。会社が販売する株式と既存株主の売出しが含まれ、会社への手取り調達額でも、時価総額でもない。計算式は980,000,000株×83ドル。［A1、独自計算］

| 確認対象 | 今回の確認結果 |
|:--|:--|
| 公開価格 | 83ドル。会社正式発表で確認 |
| 最終条件での上場後発行済・流通株式数 | 未確認。発行済数、自己株式控除後株数、募集株数を区別して再照合する |
| 完全希薄化後株式数 | 未確認。オプション・RSU・転換証券等の扱いを照合する |
| IPO価格ベースの時価総額 | 最終株数の照合未了につき未確認 |
| PSR（株価売上高倍率） | 最終時価総額が未確認のため算定を保留 |
| 最終手取り調達額 | 最終目論見書との照合未了 |

報道には完全希薄化後評価額約1.5兆ドルとの記載があるが、これは報道値であり、本稿の確定時価総額には採用しない。［A10］ 仮条件時点の株数に83ドルを掛けるだけでは、募集規模変更や転換条件を取り込めない。

確認後は、**基本時価総額÷直近12か月売上高**を基本PSRとし、希薄化を含めた参考倍率も別掲する。株式価値に現金・負債を調整するEV／売上高とは区別する。赤字期のPERは割安判断に使わない。

### 売上・損益・営業キャッシュフロー

単位：百万米ドル。米国GAAP・連結。2026年1〜9月は未監査。出所はS-1/Aの連結財務諸表・MD&Aで、11月17日提出版とも主要数値を照合した。［A11・A12］

| 指標 | 2025年通期 | 2025年1〜9月 | 2026年1〜9月 |
|:--|--:|--:|--:|
| 売上高 | 4,585 | 2,545 | 33,242 |
| 営業損益 | −8,060 | −5,224 | −1,260 |
| 純損益 | −41,965 | −25,107 | −104,039 |
| 営業キャッシュフロー | −2,637 | −2,024 | ＋6,569 |
| 計算資源・インフラ費用 | 7,326 | 4,381 | 18,808 |

1〜9月売上は前年同期比約1,206％増、営業利益率は約−3.8％。直近12か月の売上は35,282百万ドル（352.82億ドル）となる。計算式は4,585＋33,242−2,545。増収率は（33,242÷2,545−1）×100、営業利益率は−1,260÷33,242×100。［A11・A12、独自計算］

純損失には転換証券等の公正価値変動損94,324百万ドルが含まれる。純損失をそのまま現金流出と解釈せず、営業損益とCFを併せて見る。ただし、資金調達条件と株主の負担を無視してよいわけではない。［A11］

**分析：** 急成長と営業赤字縮小は前向きな材料だが、現在の成長率の持続を前提にはしない。営業CFの黒字も、資金回収・支払時期と今後の投資負担を含めて評価する必要がある。

### AIに必要な費用と、現金創出の見方

モデルの学習と利用時の推論には計算資源が必要だ。開示される「計算資源・インフラ費用」は、推論原価だけを示すものではない。現在の損益計算書は費用の性質別表示であり、粗利益を別掲していない。そのため、売上からこの費用だけを引いて粗利益率とはしない。［A12］

S-1/Aでは、9月末時点とその後に締結した契約を含め、購入・リース等のコミットメントは約9,009億ドル、9月末から12か月以内の支払期限分は約707億ドルとされる。ほぼ全額が計算資源・インフラに関係する。**複数年の契約額であり、当期費用・年間設備投資額・現在の借入残高とは異なる。**［A9］

会社定義のFCFは今回未確認とする。継続監視では、営業CFから何を控除するかを定義し、有形固定資産取得、設備等の前払金、リース、計算資源への支払いを照合する。投資CF全体を設備投資として差し引くことはしない。

調達資金の使途は、計算資源・インフラ、人材、運転資金等で、買収・投資やRSU決済に伴う税支払いにも充当し得るとされる。最終条件での金額は別途確認する。［A12］

## ④ OpenAI・Googleとの競争

以下は各社の公式製品情報を基にした比較で、競争上の意味は本稿の分析である。［A4・A5・A13・A14・A15］

| 観点 | Anthropic | OpenAI | Google／Gemini |
|:--|:--|:--|:--|
| 企業向け市場 | Claudeの業務導入、API組み込み、クラウド経由販売 | ChatGPTの法人利用とAPI・エージェント基盤 | Google Cloudや既存の業務環境からの導入 |
| 開発者向け | Claude Code、Claude API | Codex、API、Agents API | Gemini Code Assist、Gemini関連API |
| 技術競争の評価軸 | 実務の完遂率、品質、運用の安定性 | 同左 | 同左 |
| 収益化の入口 | 従量課金と契約・購読 | 法人契約・購読とAPI利用 | クラウド利用と関連サービスの契約 |
| 投資上の論点 | 導入の深まりが利益に結び付くか | 製品・販売基盤の広さが競争圧力になる | インフラと販売基盤の一体運営が競争圧力になる |

**分析：** 一度のベンチマーク首位よりも、顧客の業務で「正しく完了できるか」「必要な時間と費用はどれだけか」「継続運用できるか」を重視する。複数モデルの併用やオープンウェイトモデルも競争相手になる。

今回はOpenAIの未公開財務数値を採用しない。Googleの親会社Alphabetの全社・クラウド業績も、Gemini単独の売上・利益ではない。期間・会計範囲が揃わない数値を並べて収益性の順位は付けない。

## ⑤ 長期保有する理由――四つの仮説と反証条件

以下は本稿の投資仮説であり、将来予測の保証ではない。

| 投資仮説 | 現時点の根拠 | 仮説を見直す条件 |
|:--|:--|:--|
| 企業向け生成AI市場が拡大する | 複数社の法人・開発者向け製品展開とAnthropicの増収は、導入拡大と整合する | 顧客の本番利用・更新が伸びず、実証実験後の縮小が広がる |
| Claudeが企業・開発者市場で競争力を持つ | 会社IPOサイトは9月末のTTM売上10万ドル以上の顧客が11,900超と説明。Claude Codeも実作業を担う製品として提供 | 大口顧客の利用縮小や他社移行が続き、値下げでも需要を維持できない |
| エージェント普及がAPI・Claude Code需要を広げる | 作業を複数工程にわたって任せる製品と課金の仕組みが存在する | 実務の成功率・安全性・費用対効果が改善せず、利用拡大が収益につながらない |
| 売上成長が利益・CF創出につながる | 累計営業赤字の縮小と営業CF黒字化 | 売上増でもGAAP利益率と投資後の現金収支が改善せず、外部調達依存が深まる |

根拠資料：顧客指標はA16、製品はA4・A13・A14・A15、財務はA11。企業市場全体の将来成長率を示す独立した市場予測は、本稿では採用していない。Anthropic一社の伸びを市場全体の成長率と同一視しない。

**分析：** AIエージェントが増えても、効率化や単価低下で利用量と売上の伸びは一致しないことがある。利用が増えたときに追加費用を上回る粗い経済的余剰を生むかを検証する。利益率の開示がなければ、確認できないまま残す。

これらは監視方針の提案であり、自動監視や通知の設定を開始したという意味ではない。次回決算発表日時は今回未確認。過去の発表日から推測しない。

## ⑧ 私の投資方針

今回当選した11株は、長期保有を基本とする。IPO直後の株価変動だけを理由に売却せず、事業の成長性、競争優位性、財務状況を継続的に評価する。

ただし、長期保有は判断を固定することではない。企業・開発者向けの競争力が失われる、成長しても利益や現金が残らない、希薄化で1株当たりの価値が損なわれるなど、投資仮説が崩れた場合には保有方針を再検討する。

## ⑨ まとめ

**本稿の分析として期待するのは、Claudeが企業の業務とソフトウェア開発に定着し、継続的な需要を生むことだ。** その需要が、必要な費用と投資を上回る利益・現金につながるかが長期投資の焦点になる。

一方、最終株式数に基づく時価総額とPSR、製品別収益性、将来の計算資源への支払負担には確認課題が残る。現段階で83ドルを割安とは判定しない。

IPO当選は投資の出発点であり、その成功が将来の株価上昇を保証するものではない。今後の決算で仮説を検証し、その結果を記録していく。
