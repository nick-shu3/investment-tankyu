対象は**2027年3月期第2四半期（中間期）、2026年4月1日〜9月30日の6か月累計、IFRS・連結**。会社の2026年度上期に相当する。前年同期は2025年4〜9月。発表日は2026年11月4日、分析・評価日は11月5日。**業績評価：好調。株価評価：未実施。**

## 主要業績

単位は百万円、EPSは円。増減率は会社開示値。営業利益は日本の会計慣行に従う参考表示で、持分法投資損益や有価証券損益を含まない。[I1 PDF p.2、p.8]

| 指標 | 2026年度上期 | 2025年度上期 | 前年同期比 |
|:--|--:|--:|--:|
| 収益 | 7,929,747 | 7,249,159 | +9.4% |
| 営業利益 | 413,188 | 354,140 | +16.7% |
| 税引前利益 | 703,469 | 661,959 | +6.3% |
| 当社株主帰属中間純利益 | 580,472 | 500,280 | +16.0% |
| 基本的EPS | 83.06 | 70.84 | — |

営業利益率は5.21%（413,188÷7,929,747）、前年4.89%（354,140÷7,249,159）。いずれも独自計算。前年EPSは2026年1月の株式分割を遡及して調整した会社表示。[I1 p.2、p.8]

## 何が良かったのか：増益の中身

会社独自指標の**基礎収益は上期5,045億円、前年3,790億円から33%増**。IFRS純利益から会社が区分した一過性損益を除いた管理指標で、営業利益や営業CFとは異なる。会社は、既存事業の成長や新規投資の寄与に加え、為替が約190億円、資源価格が約40億円の押し上げ要因だったと説明する。外部環境の影響を含むため、増分全額を事業の数量・採算改善とは扱えない。[I2 p.2、p.7]

会社開示の四半期単独の基礎収益は、今期Q1が2,495億円、Q2が2,550億円。Q1後も高い水準を維持したが、同一水準が将来も続く保証ではない。[I2 p.4]

## 事業別分析

以下は会社表示の**上期基礎収益、億円・概数**。持分法損益を含む管理指標で、各事業の営業利益ではない。会社は組織変更を反映し、前年も組み替えている。ファミリーマートの取込損益は食料と第8に3対7で配分する。[I2 p.8〜9、p.28]

| 区分 | 2026年度上期 | 2025年度上期 |
|:--|--:|--:|
| 繊維 | 307 | 237 |
| 機械 | 882 | 589 |
| 金属 | 927 | 635 |
| エネルギー・化学品 | 509 | 352 |
| 食料 | 662 | 559 |
| 住生活 | 291 | 180 |
| 情報・金融 | 484 | 395 |
| 第8 | 245 | 214 |
| その他及び修正消去 | 738 | 625 |

機械は北米電力の売電収入や日立建機の取込比率上昇、金属は豪州原料炭事業の操業改善や石炭価格・為替が寄与。食料ではDoleの加工食品が増益の一方、日本アクセスは物流費増加などで減益。情報・金融ではCTCの取引が好調だった。住生活の増益には前年の損失取込が連結除外でなくなった反動もある。**分析：** 幅広い増益は強みだが、価格・為替・持分変更・前年の損失反動を分けて持続性を見る必要がある。[I2 p.9]

## 純利益の質

| 損益項目 | 2026年度上期 | 2025年度上期 |
|:--|--:|--:|
| 営業利益 | 413,188 | 354,140 |
| 有価証券損益 | 44,268 | 136,030 |
| 持分法による投資損益 | 230,502 | 160,239 |
| 税引前利益 | 703,469 | 661,959 |
| 法人所得税費用 | −104,770 | −143,132 |
| 当社株主帰属中間純利益 | 580,472 | 500,280 |

単位は百万円。表は主な項目を抜粋し、全項目を足し合わせた計算表ではない。[I1 p.8]

有価証券損益は前年の売却益の反動で減少。持分法利益の増加や税金費用の減少が利益を支えた。会社は東京センチュリーの社債型種類株式引受や日立建機追加取得に伴う税金費用改善を説明する。[I1 p.6]

会社が区分する上期の一過性損益は**760億円**（前年1,215億円）。主要内訳はCIECO Azer関連売却390億円、東京センチュリー関連255億円、日立建機関連95億円。これらは会社の税後等の管理区分であり、上表の税前の個々の勘定を単純に控除した値ではない。**分析：** 一過性要因が前年より縮小する中での増益は前向きだが、基礎収益にも市況・為替の影響がある。[I2 p.2、p.7、p.30]

## キャッシュフローと財務

単位は百万円、上期累計。FCFは会社開示の「営業CF＋投資CF」をCF計算書から再計算した値で、設備投資だけを控除したものではなく投資回収も含む。[I1 p.7、p.13]

| 指標 | 2026年度上期 | 2025年度上期 |
|:--|--:|--:|
| 営業CF | 293,175 | 609,245 |
| 投資CF | −152,062 | −80,924 |
| FCF（営業CF＋投資CF） | 141,113 | 528,321 |
| 財務CF | −175,581 | −498,596 |

営業CFは前年より減少。会社は食料・情報金融・エネルギー化学品での運転資金増加などを説明する。持分法利益は会計上の利益であり、そのまま当期の現金入金ではない。**分析：** FCFはプラスを維持したが、Q1から続く資金回収の弱さはなお検証が必要。[I1 p.7、I2 p.33]

| 財務指標 | 2026年9月末 | 2026年3月末 |
|:--|--:|--:|
| 現金及び現金同等物（百万円） | 557,387 | 593,766 |
| 有利子負債（億円） | 41,628 | 36,727 |
| ネット有利子負債（億円） | 35,352 | 30,243 |
| 株主資本比率 | 39.5% | 39.4% |
| NET DER | 0.52倍 | 0.46倍 |

有利子負債・ネット有利子負債・NET DERは会社表示。自己株取得、配当、日立建機や伊藤忠食品への追加取得などが負債増の要因と会社は説明する。6月末のNET DERは0.51倍で、9月末は0.52倍。利益成長に加え、投資の回収と金利負担を追う。[I1 p.7、p.10、前回記事]

会社は通期の成長投資をCAPEXを含め1.5兆円と見込む。上期実績4,880億円と決定済み案件を合わせ約1.2兆円を積み上げたと説明するが、**決定済みと実行済みは異なる**。電通総研へのTOBは説明資料時点で実施中、ACGについては決定済み案件として記載されている。将来の回収・利益寄与を確認する。[I2 p.6、p.26]

## 通期見通し・今後の注目点

**会社見通し：** 通期の当社株主帰属純利益9,500億円、基礎収益9,000億円。上期の進捗率はそれぞれ61%、56%。年間配当予想は中間22円・期末22円の計44円。進捗率が高いだけで上方修正を予測しない。[I1 p.2〜3、I2 p.2]

1. 為替・資源価格と、非資源事業の利益成長の持続性。
2. 北米電力、原料炭、CTC、物流費などの事業別採算。
3. 在庫・債権等の運転資金回収と、投資先からの配当入金。
4. ACG・電通総研などの取引の実行状況、資金支出と投資採算。
5. ネット有利子負債、金利負担、自己株取得と通期計画。

次回決算の正確な発表日時は未確認。[公式IRカレンダー](https://www.itochu.co.jp/ja/ir/calendar/index.html)で確認する。

**総合評価：好調（2026年11月5日）。** 利益成長は幅広いが、営業CFの減少と負債増加を伴っている。業績評価は株価の割安・割高や売買推奨を意味しない。
