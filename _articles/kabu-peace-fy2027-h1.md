株式会社カブ＆ピースの**2027年1月期上期**（2026年2月1日〜7月31日、6か月累計）。連結・日本基準。半期報告書提出・説明資料公表は2026年10月29日。分析更新日・評価日は同日。2027年1月期の**通期決算は未公表**。同社は非上場で、証券コードは確認できない。**株価評価：未実施**。業績評価は「好調」だが、半期の改善を評価したもので、上場の実現や株式の値上がりを予測するものではない。

## 主要業績と黒字化

単位は百万円、連結。端数は半期報告書の千円表示を百万円に換算し小数第2位に丸めた。出典：S1 p.34。

| 指標 | 2027年1月期上期 |
|:--|--:|
| 売上高 | 5,173.86 |
| 売上総利益 | 3,164.37 |
| 販売費及び一般管理費 | 2,752.20 |
| 営業利益 | 412.17 |
| 経常利益 | 399.80 |
| 親会社株主に帰属する中間純利益 | 316.93 |
| 基本的1株当たり中間純利益 | 0.08円 |

営業利益率は**約8.0%**（412,172千円÷5,173,861千円、独自計算）。会社は広告運用の効率化、開発業務の内製化、カスタマーサポート費用の相対的な負担低下を改善要因として挙げる。S1 p.10、S2 p.29。

会社説明資料では、前年上期の営業損失1,121百万円に対し、今回上期は営業利益412百万円。ただし**前年は単体、今期は連結**で、子会社を含む範囲が異なる。増減率は参考にとどめる。前期通期の営業損失は連結で1,496百万円だが、12か月と6か月なので単純比較できない。前年連結の数値は買収会計の確定を反映している。S1 p.2、S2 p.29。

## 事業別の動き：利用金額と売上は違う

事業は単一セグメント。会社が開示する上期のサービス別売上は以下のとおり。単位は百万円、S1 p.12。各サービスの利益は未確認。

| サービス | 売上高 |
|:--|--:|
| モバイル | 1,416.55 |
| プラス・PREMIUM | 861.15 |
| ひかり | 571.05 |
| Wi-Fi | 366.89 |
| カード | 331.26 |
| でんき | 256.87 |
| ウォーター | 255.84 |
| その他を含む全社 | 5,173.86 |

モバイルは全社売上の約27.4%（1,416,553÷5,173,861、独自計算）。**上期のサービス利用金額は807.35億円だが、売上高51.74億円とは異なる。** 利用金額は各サービス利用者の支払額の合計であり、カード利用額などが含まれる。売上高は会社が収益認識した額で、株引換券に相当する額を控除後の数値である。S1 p.11〜12。

2026年7月末の延べサービス利用者は107.4万人。複数サービス利用者は重複するため、実人数や株主数ではない。ストック型は期末契約数、スポット型は直近1年の利用者を集計。カブアンド種類株式の株主数は2026年6月19日時点で101万4,293人。S1 p.10〜11。

## 利益とキャッシュフローの質

上期連結、百万円。S1 p.32〜34、37。

| 指標 | 2027年1月期上期・期末 |
|:--|--:|
| 営業キャッシュフロー | 2,967.81 |
| 投資キャッシュフロー | −470.22 |
| 財務キャッシュフロー | −767.11 |
| 現金・現金同等物（7月末） | 3,792.87 |
| 自己資本比率（7月末） | 57.1% |

営業CFの内訳には株引換券に係る負債の増加1,161.27百万円と契約負債の増加716.01百万円が含まれる。会社は後者に年間プランの前受け等が含まれると説明。これらには将来のサービス提供や株引換・割引券の処理が関係し、営業CFの全額を持続的な利益と同一視できない。S1 p.12〜13、37、39。

財務CFには株式発行による収入1,557.40百万円と、前払式支払手段の発行による支出1,557.40百万円の両方が計上されている。差し引き後は主に借入返済により財務CF全体で767.11百万円の支出。増資額だけを現金増加と見なさない。期末貸借対照表の株引換券に係る負債残高は837.69百万円であり、キャッシュフロー計算書上の増加額とは同じ数値ではない。S1 p.32、36〜37。

有形固定資産取得5.35百万円、無形固定資産取得460.10百万円。参考として営業CFから両取得額を差し引くと**2,502.35百万円**（2,967.812−5.354−460.103、単位百万円、独自計算）。会社開示のFCFではなく、株引換券・契約負債の影響を含む。自己資本比率は前期末44.9%から57.1%に上昇したが、新株発行も要因である。S1 p.2、36〜37。

## 今後の成長とリスク

会社は太陽光・蓄電池などを活用する新事業「ウチカラ」を準備中。決算期末後の2026年10月11日時点の申込件数は95,553件であり、**設置済み件数や収益化済み件数ではない**。会社は11月中旬から設置、2027年1月上旬からサービス開始を予定する。設備調達・施工・市場価格・制度変更などが収益に影響し得る。S2 p.23、S1 p.8。

会社は2027年春頃を最短上場時期の目安とするが、取引所の承認等が必要であり、上場日も上場そのものも確定していない。2026年12月22日に10株を1株に併合予定で、1株未満の端数について会社は金銭支払いを予定すると説明。上場後の株価や株引換券の交換制度は未確定。S3。

**分析**：初の半期営業黒字は前進だが、ふるさと納税や電気・ガスには季節性がある。サービス別利益やウチカラの投資回収が未確認のため、上期の利益を通期や将来へ単純に延長できない。通期業績予想と次回決算発表日は確認できていない。S1 p.8〜9。

## 次回の確認点

1. 下期・通期でも営業黒字が続くか、季節要因を分けて確認する。
2. モバイルと会員サービスの売上、費用効率、解約率の推移。
3. 株引換券・契約負債の処理と営業CFの内訳。
4. ウチカラの設置数、設備投資、調達方法、収益化と回収期間。
5. 上場審査・承認の状況と株式の取扱いに関する正式発表。
