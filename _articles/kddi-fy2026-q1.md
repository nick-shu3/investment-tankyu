**KDDI株式会社（9433）**は東京証券取引所プライム市場に上場する研究対象企業である（K0）。対象は**2027年3月期第1四半期、2026年4月1日〜6月30日、IFRS・連結**。FY2026-Q1と同一期間である。**公表日：2026年8月7日。分析・評価日：2026年10月29日。業績評価：好調。株価評価：未実施。** 最新公表済み決算はQ1と公式資料一覧で確認した（K1、K5）。本人コメントは未提供のため掲載しない。

<h2 id="results">主要業績と利益の質</h2>

表は**百万円、EPSのみ円**。会社開示値は百万円未満四捨五入（K1 PDF通しp.1〜2、10）。

| 指標 | 当期Q1 | 前年Q1 |
|:--|--:|--:|
| 売上高 | 1,487,316 | 1,415,734 |
| IFRS営業利益 | 314,248 | 259,473 |
| IFRS親会社帰属純利益 | 195,465 | 160,069 |
| 基本EPS | 51.34 | 40.23 |
| 希薄化後EPS | 51.33 | 40.22 |
| 調整後営業利益 | 314,262 | 259,473 |
| 調整後親会社帰属純利益 | 193,442 | 159,094 |

売上高は前年同期比**5.1%増**、IFRS営業利益は**21.1%増**、親会社帰属純利益は**22.1%増**。営業利益率は独自計算で18.33%から21.13%へ改善した。会社の調整後利益は、非経常損益やポートフォリオ見直しに伴う一時損益を除いた非IFRS指標であり、IFRS実績と区別する（K1 PDF通しp.1〜2、K2 p.12）。

営業利益には持分法投資損益11,365百万円を含む。税引前利益308,466百万円から法人所得税87,009百万円を差し引いた四半期利益221,457百万円のうち、非支配持分25,992百万円を控除して親会社帰属純利益195,465百万円となる。金融費用は前年7,948百万円から11,619百万円に増えた。端数差は会社の四捨五入による（K1 p.10）。

**AI分析：** 増収と利益率の改善は評価できるが、調整後利益を保証された正常利益とはみなさない。EPSの増加には利益の増加に加えて期中平均株式数の減少も影響する。前四半期比は季節性・事業構成の条件を今回そろえていないため省略する。

<h2 id="segments">事業別分析</h2>

2027年3月期からセグメント区分を変更し、前年は新しい区分へ組替済み。以下の利益は**会社定義の調整後営業利益**、売上高はセグメント間取引を含む百万円で、連結売上にそのまま加算しない（K1 p.5、K2 p.4〜6）。

| 事業 | 当期利益 | 前年利益 |
|:--|--:|--:|
| テレコムコア | 210,706 | 176,317 |
| パーソナルグロース | 55,491 | 50,773 |
| ビジネスグロース | 18,453 | 15,180 |

**通信：** テレコムコアはモバイル収入増などで利益19.5%増。会社は調整後営業増益548億円のうち、通信収入の管理上の利益増を180億円と説明する。モバイルARPUは前年Q1の4,240円から4,400円へ上昇。定義には通信料等に加え端末補償サービス等を含み、単純な基本料金と同一ではない。ARPUの前年値はセグメント変更に合わせ修正されている（K2 p.8・12、K3 p.7・9）。

**個人向け成長事業：** パーソナルグロースはデバイス関連収入やローソンの持分法投資利益の増加等で増益。一方、auフィナンシャルホールディングスのIFRS営業利益は117億円から80億円へ減少し、会社は預金増強と時価評価損の影響を挙げる。金融収入の増加だけで利益改善を判断しない（K1 p.5、K3 p.15〜16）。

**法人向け：** ビジネスグロースはサイバーセキュリティ・AIインテグレーション、データセンターの収入増などで増収増益。AIやDCの需要は成長機会だが、投資額、稼働率、収益化までの期間を継続確認する（K1 p.5、K3 p.15）。

**AI分析：** 通信契約を基盤に金融・法人サービスを組み合わせる事業構造は強みである。新たなサービスの採算、競合との料金競争、金融資産の評価損や信用リスクを合わせて追う。

<h2 id="finance">財務・キャッシュフロー</h2>

**百万円、Q1の3か月、連結**（K1 p.8〜9・14〜15）。

| 指標 | 当期Q1 | 前年Q1 |
|:--|--:|--:|
| 営業CF | −113,535 | 331,099 |
| 投資CF | −144,380 | −241,588 |
| 会社開示FCF | −257,914 | 89,512 |
| 財務CF | −37,100 | −45,144 |
| 期末現金・現金同等物 | 786,926 | 963,507 |
| 有形固定資産の取得支出 | −82,997 | −88,255 |
| 無形資産の取得支出 | −72,913 | −66,291 |

会社定義の**FCF＝営業CF＋投資CF**。短信の百万円表示を用いた当期の独自計算は−113,535−144,380＝−257,915百万円で、会社開示−257,914百万円との差1百万円は丸めによる。設備投資支払額は有形・無形の取得支出合計155,910百万円である。

営業CFには金融事業の借入金の増減**−664,000百万円**、貸出金の増減＋155,192百万円、預金の増減＋93,763百万円等が含まれる。前年の金融事業借入金は＋360,000百万円だった。会社は借入金が増加から減少へ転じたことなどを営業CF悪化の要因に挙げている。金融取引を含む連結CFの赤字だけで通信本業の収益力や資金繰りを断定しない（K1 p.7・14）。

会社開示の基礎FCFは−314,007百万円で、**営業CF−設備投資−リース＋税引後純利息支払額**という別定義。投資CF全体を使う上表のFCFと混同しない（K2 p.2）。

6月末の借入金・社債は流動2,137,203百万円、非流動2,511,474百万円。金融事業の預金は流動5,645,963百万円、非流動114,752百万円で、銀行預金を一般事業会社の借入金と同一視しない。財務CFには自己株式取得のための預け金250,000百万円の支出が含まれるが、同額の自己株式をQ1に取得済みという意味ではない（K1 p.9・15）。

<h2 id="outlook">見通しと次回の確認点</h2>

会社は通期予想を据え置き、売上高6兆4,100億円、調整後営業利益1兆2,100億円、調整後親会社帰属純利益7,310億円を見込む。年間配当予想は**84円**（中間・期末各42円）で、前期実績80円から増配を予定する。これらは予想であり確定実績ではない（K1 p.1〜2）。

次回決算は**2026年11月6日予定**。発表時刻は今回未確認で、既存カレンダーの日付と一致する（K5）。

1. 通信ARPUと主要回線・解約率の改善が収益と利益に続くか。
2. 金融事業の預金・信用費用・有価証券評価損と収益性。
3. 法人向けAI・DCの受注、稼働と投資回収。
4. 金融事業を含む連結CFと会社の基礎FCFの差、借入・還元の資金負担。
5. 通期予想の前提と、費用投下・競争環境の変化。

**総合評価：好調（2026年10月29日）。** 通信が利益を押し上げ、法人・個人向け成長領域も増益。一方、金融の減益と連結CFの変動は監視が必要。株価の割安・割高や売買推奨は評価していない。初回分析のため前回記事との予想検証はない。
