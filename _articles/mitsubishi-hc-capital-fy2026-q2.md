## 主要業績：反動と新たな損失が重なった

単位は百万円、EPSは円。前年は決算期変更による取込期間差を含む開示実績。短信はレビュー対象外、半期報告書には期中レビュー報告書が付く。[H1 p.1、H4 p.2・16・32〜33]

| 指標 | 前年上期 | 当上期 | 会社開示の前年同期比 |
|:--|--:|--:|--:|
| 売上高 | 1,127,424 | 1,109,643 | −1.6% |
| 営業利益 | 129,962 | 93,785 | −27.8% |
| 営業利益率（独自計算） | 11.53% | 8.45% | −3.08pt |
| 経常利益 | 123,980 | 91,867 | −25.9% |
| 親会社株主帰属純利益 | 88,793 | 24,956 | −71.9% |
| 基本EPS | 61.85 | 17.40 | — |

前年にはelfc・CAI・PNWの決算期変更による追加取込があり、純利益を約228億円押し上げていた。会社はこの影響を除いた前年純利益を659億円とし、当上期249億円との差を410億円減、62.2%減と説明する。**同一期間へ調整しても大幅減益**である。[H2 PDF p.3・7〜8・33]

会社の比較用指標は、インカムゲインが前年調整後1,943億円から2,174億円、アセット関連損益は238億円から78億円。前者は「アセット関連損益控除後の売上総利益＋営業外損益（償却債権取立益を除く）」で、販管費控除後の純利益でも現金収入でもない。伸びには為替も寄与し、為替影響除外の増加額は112億円とされる。[H2 PDF p.2・7〜8]

**AI分析：** 基礎的な収益の積み上げは認められるが、資産売却・評価損益と信用費用が悪化した。インカムゲインの増加だけで全社の収益力回復を結論づけない。

## EE評価損：非現金でも投資判断上の負担は残る

会社は、持分法適用関連会社European Energy（EE）の業績が、電力価格の変動や送電容量の増強遅延を背景に出資時の想定を下回り続けたと説明する。保有株式を回収可能価額まで減額し、**7〜9月に378億円の関係会社株式評価損を特別損失へ計上**した。[H3 p.1]

全社損益計算書の関係会社株式評価損は**38,146百万円**であり、EE分37,800百万円と同額ではない。営業利益から最終利益までの主な橋渡しは次の通り。[H4 p.16・21]

| 当上期・百万円 | 金額 |
|:--|--:|
| 営業利益 | 93,785 |
| 営業外収益／営業外費用 | 6,560／8,478 |
| 経常利益 | 91,867 |
| 特別利益／特別損失 | 226／38,146 |
| 税前利益 | 53,947 |
| 法人税等 | 29,031 |
| 中間純利益 | 24,915 |
| 非支配株主帰属純損失 | −40 |
| 親会社株主帰属純利益 | 24,956 |

端数切捨てにより合計差がある。EE株式の評価損と、通常の持分法損益は別項目。会社資料はEE特別損失控除前の純利益627億円も示すが、**会社が示す当該項目の除外値**であり、他の売却・評価損益まで除いた正常利益ではない。[H2 PDF p.8]

**AI分析：** 評価損はCF計算上加算調整されるが、投資価値の毀損という意味は消えない。税効果や他の費用を推測し、税前の378億円を独自に加えた額を「本来の利益」と断定しない。追加評価損の有無、案件売却と回収可能性を追いたい。

## 6事業：航空・海外の改善と、不動産・国内信用費用の悪化

以下は会社概要資料の**億円概数・税後セグメント利益**。営業利益ではない。前年は新区分・費用配賦へ組替済みで、決算期変更効果を除いた会社比較を掲載する。端数差により単純合計と一致しない。[H2 PDF p.10〜11]

| 事業 | 前年上期・期間調整後 | 当上期 |
|:--|--:|--:|
| カスタマーソリューション | 183 | 138 |
| 海外カスタマー | 26 | 129 |
| 環境エネルギー | −36 | −433 |
| 航空 | 181 | 258 |
| ロジスティクス | 151 | 151 |
| 不動産 | 157 | 5 |
| 調整額 | −4 | 0 |

- **カスタマーソリューション：** 収益性の高い資産を積み上げた一方、個別案件の大口貸倒引当金等が減益要因。会社の貸倒関連費用は9億円から65億円へ増加。
- **海外カスタマー：** 欧州の伸長、英国自動車ローン手数料問題に係る前年費用の反動、米州トラックの貸倒費用減が寄与。成長と費用反動を分けて見る。
- **環境エネルギー：** EE評価損が中心。評価損を除いた後も事業自体の採算・回収を確認する必要がある。
- **航空：** 表面比較では271→258億円だが、期間調整後は増益。エンジンの資産積み上げと売却益、航空機減損の減少が寄与する。前回懸念したオフリースが全面解消したとまでは確認していない。
- **ロジスティクス：** 期間調整後は概ね横ばい。コンテナ売却益・貨車リース料の改善と、貨車売却益の減少が併存。
- **不動産：** 売却益の減少と米国不動産の時価評価損が重い。インカム増だけでは補えなかった。

出典：H2 PDF p.8・11・17・21・39。**全社貸倒関連費用は130→164億円**で、Q1時点の改善から変化した。会社の管理指標と、PLの貸倒引当金繰入額・償却債権取立益を再加算・再控除しない。

## 財務・CF：営業赤字ではなく「営業CF赤字」の中身を見る

半期報告書により、前回未確認だったCFを確認できた。単位は百万円、6か月累計。[H4 p.2・18〜19]

| 指標 | 前年上期 | 当上期 |
|:--|--:|--:|
| 営業CF | −32,246 | −124,958 |
| 投資CF | −32,363 | −10,972 |
| 財務CF | 77,861 | 75,775 |
| 期末現金・現金同等物 | 298,544 | 281,519 |

当期首の現金同等物は346,045百万円。3つのCF合計−60,155百万円と為替換算差額−4,369百万円等を経て減少した。端数差があり、前年上期末残高を当期首として差し引かない。

営業CFには**賃貸資産取得549,535百万円**が含まれ、前年454,312百万円から増加。利息支払150,477百万円、税金支払36,626百万円も含む。EE評価損等は非現金項目として調整されている。社用資産取得4,638百万円は投資CFに計上され、賃貸資産の取得と区別する。[H4 p.18]

**AI分析：** 金融・リース企業では営業資産への投資が営業CFへ入るため、赤字だけで本業の不採算や資金危機とは判断できない。一方、現金流出は現実であり、回収・調達との対応が必要だ。営業CFから賃貸資産取得を再控除すると二重計上になる。本記事では一般事業会社型のFCFを採用しない。

9月末の自己資本比率は15.2%、総資産13,092,983百万円、純資産2,013,140百万円。会社の有利子負債（リース債務除外）は約9兆8,941億円で3月末比約137億円増。資金原価は会社表示1,366→1,513億円、10.8%増で、売上原価に含まれる。営業外支払利息とは区分が異なる。[H1 p.1、H4 p.7、H2 PDF p.40]

負債は営業資産を支える事業資金である。資産・負債の通貨と満期、調達費用の転嫁、借換え条件を継続確認する。

## 通期下方修正と配当維持：下期への依存は残る

会社は純利益予想を**1,600→1,300億円、18.8%下方修正**。EPS予想は111.57→90.62円。年間配当予想は51円（中間25円、期末予想26円）を維持し、前年年間46円を上回る。[H1 p.1、H3 p.1〜2]

会社は今回の損失が中長期の収益力等へ与える影響は大きくないと判断している。ただし予想の据え置きは将来の配当保証ではない。会社表示の予想配当性向は56.3%。[H2 PDF p.3〜4・24]

修正計画ではPLの想定為替を1ドル150→158円、1ポンド205→215円へ変更。カスタマーソリューションの下振れを資産・政策保有株式売却などで補い、専門事業では下期の不動産売却や航空・物流の利益でEE損失の一部挽回を目指す。これらは会社計画であり未達リスクがある。[H2 PDF p.4・24]

## 総合評価と次回の確認点

**業績評価：注意（2026年11月17日）。** 海外・航空の改善は評価するが、EE評価損と下方修正に加え、不動産・国内信用費用に懸念がある。営業CF赤字は営業資産取得を含む構造として解釈し、利益と資金の両面を追う。株価の割安・割高判断、買い推奨とは別である。

1. EEの追加損失、回収可能価額の前提、実際の案件売却・入金。
2. 国内大口貸倒案件の追加費用と海外の信用費用の推移。
3. 下期不動産売却・政策保有株売却の利益額と現金回収。
4. 航空のオフリース・整備・再稼働、エンジン収益の継続性。
5. 営業資産取得と回収、借換え・資金原価、配当予想の前提。
