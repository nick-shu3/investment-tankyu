# 未確認事項台帳

最終更新：2026年11月11日

決算記事・コラムに関する重要な未確認事項を手動で管理する。この記事一覧は全記事の網羅的な監査結果ではない。発表予定日を過ぎただけで確認済みとしない。会社説明・事実・独自分析を区別し、出典で確認できない数値を補わない。

## 管理方法

- 新規記事の作成・更新時に、投資判断や分析の理解に影響する未確認事項を追加する。
- 状態は「未確認」「一部確認」「確認済み」「確認不能」を用い、最終確認日、確認した内容、次の確認先、関連記事を記録する。発表予定日と実際の公表は区別する。
- 進展があれば、根拠となる公式資料のURL・公表日・ページを記し、履歴を残す。記事を訂正・追記する場合は記事側にも日付と理由を記載する。
- 本ファイルと履歴は公開される。個人の保有数量・取得単価・損益・売買履歴等の非公開情報は記載しない。
