### 基礎収益は会社独自の指標で、市況・為替も含む

I2 p.2・4〜5は、純利益を**基礎収益約2,495億円と一過性損益445億円**に区分する。前年は約1,810億円・1,030億円。基礎収益は会社が一過性と区分した損益を除く管理指標であり、IFRSの営業利益や本記事が推計した正常利益ではない。会社概数のため、足し算と純利益2,938億円は厳密には一致しない。

会社説明では**基礎収益＋685億円、一過性損益−585億円、連結純利益＋98億円**。基礎収益の増加を次のように分解している（I2 p.4）。各社の個別増益をこの表へ再び加算しない。

| 会社による増益要因（億円） | 前年同期比 |
|:--|--:|
| 資源価格影響 | ＋40 |
| 為替影響 | ＋120 |
| 中東情勢のネット影響 | ＋50 |
| 前年不調事業の改善・連結除外等 | ＋50 |
| 新規投資（前年度実行分を含む） | ＋110 |
| 会社がオーガニック成長と分類する部分 | ＋315 |
| 合計 | ＋685 |

非資源の基礎収益は1,535→2,115億円、資源は275→380億円で、ともに会社表示38%増。**非資源比率85%は基礎収益の構成比**であり、売上比率ではない。一過性込みの純利益の非資源比率は76%で、別の指標である（I2 p.4〜5）。

AI分析：投資先の販路・運営改善、IT需要、電力需要などの成長が複数事業へ広がった点は強い。一方、連結除外による赤字取込の消失と事業そのものの数量増は異なる。新規投資による利益増にも追加資本の負担があり、利益増だけで投資効率の改善とはしない。

また会社は、化学品の市況高騰によるQ1の追い風には一時性があり、資源・為替・中東の影響は今後逆風にもなり得ると説明する。**基礎収益も外部環境から独立した利益ではない**。Q1の約2,500億円を4倍して年間1兆円の実力とみなさない（I3 p.1〜2）。

### 会社独自の「実質CF」と実際の現金収支は別

I2 p.12〜13の会社管理指標は次のとおり。**億円・概数**であり、上のIFRS CFと合算しない。

| 会社管理指標 | 当期Q1 | 前年Q1 |
|:--|--:|--:|
| 実質営業CF | 2,210 | 2,450 |
| 成長投資・グロス（支出） | 3,740 | 2,970 |
| EXIT（回収） | 1,040 | 2,010 |
| ネット投資（支出） | 2,700 | 960 |
| 実質FCF | 約−490 | 約1,490 |

会社定義は、**実質営業CF＝営業CF−運転資金等の増減＋リース負債の返済等**。実質投資CFは、投資CFに非支配持分との資本取引を含め、貸付金の増減等を調整した実質的な出資・設備投資と回収。実質FCFは両者の合計で、当期は2,210−2,700＝約−490億円である。会社の「等」を含む調整の全項目を独自復元していないため、実際の営業CFとの調整差を全額運転資金とは断定しない。

成長投資3,740億円は新規投資約3,120億円とCAPEX約620億円。日立建機追加投資1,341億円・伊藤忠食品618億円などが含まれる。**支配を維持する子会社の追加取得は財務CFにも計上**されるため、投資CF718億円の支出だけを成長投資の全額としない。短信の有形固定資産等の取得・売却純額558億円も、グロスCAPEX620億円と同じ定義ではない。EXITには日立建機投資に係る貸付回収385億円等が含まれる（I1添付p.3・10、I2 p.12・31）。

I2 p.13のQ1株主還元欄は「―」だが、短信CFには配当支払1,540億円がある。**当年度の資金配分表と、前年度末配当を含む実際の受払は対応期間が異なる**。会社の実質FCF約−490億円から既払い配当を機械的に再控除して、独自の「会社開示還元後実質FCF」は作らない。

<h2 id="outlook">通期見通し・株主還元・期末後情報</h2>

**会社見通し：** 通期の親会社株主帰属純利益は**9,500億円（前年比＋5.5%）**、基本的EPS136.75円を据え置く。基礎収益9,000億円、一過性900億円、バッファー−400億円という管理上の構成で、会社表示の進捗は純利益31%・基礎収益28%。バッファーは既に発生した損失や引当金ではない。Q1進捗のみで上方修正を予測しない（I1冒頭、I2 p.2・8〜9）。

機械見通しは1,800→2,200億円、エネルギー・化学品は755→1,115億円、その他及び修正消去は1,635→875億円へ変更。主因は確定した一過性利益等の帰属先への振替であり、**全社予想の上方修正ではない**。住生活の物件売却や情報・金融の下期偏重も考慮し、部門の進捗率だけで優劣を決めない（I2 p.9、I3 p.2）。
